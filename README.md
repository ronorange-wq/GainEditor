# Gain Editor: פלאגין AU לאבלטון (Mac M1/M2/M3)

## התקנה

1. מחלצים את ה‑ZIP.
2. עושים **קליק ימני על `Install Gain Editor.command` ← Open ← Open**. בפעם הראשונה macOS שואל אם לפתוח קובץ מהאינטרנט.
3. נפתח חלון שמתקין הכול לבד:
   - אם קופץ חלון של Command Line Tools, לוחצים **Install**, ובסיום פותחים שוב את הקובץ.
   - אם כתוב שחסר CMake, מתקינים Homebrew מ‑https://brew.sh, מריצים `brew install cmake`, ופותחים שוב.
   - בפעם הראשונה ההתקנה לוקחת כמה דקות.
4. בסוף נוצר גם הקובץ **Gain Editor Installer.pkg**, להתקנה בדאבל‑קליק על מקים אחרים.
5. **באבלטון:** Settings ← Plug‑Ins ← מדליקים **Use Audio Units v2** ← לוחצים **Rescan**.

אם משהו נכשל, מצלמים את החלון ושולחים לי.

## איך עובדים

1. שמים את **Gain Editor ראשון** בערוץ של הווקאל, לפני קומפרסור ו‑EQ.
2. לוחצים **Record** בפלאגין ומנגנים את השיר באבלטון ב‑**Arrangement View**. הגל מופיע תוך כדי ניגון.
3. לוחצים שוב על **Record** כדי לעצור. ההקלטה נשמרת, והבלובים מזוהים אוטומטית.
4. עורכים. מעכשיו, בכל ניגון באבלטון השינויים מושמעים בדיוק במקום הנכון בשיר.

ההקלטה והעריכות נשמרות **בתוך הסט של אבלטון**. כשפותחים את הפרויקט מחדש הכול חוזר, גם על מחשב אחר וגם אחרי Collect All and Save.

## כלים

| כלי | מקש | מה עושים |
|---|---|---|
| Range | 1 | גוררים כדי לסמן קטע, וגוררים למעלה או למטה בתוכו |
| Envelope | 2 | לחיצה מוסיפה נקודה, גרירה מזיזה אותה, ודאבל‑קליק מוחק אותה |
| Blob | 3 | מרחפים מעל הגל וגוררים את הבלוב המודגש. **גודל הבלוב נקבע לפי הזום**: מרחוק משפט או מילה, מקרוב הברה ועד פיק בודד |
| Peak | 4 | על כל פיק שמעל הקו יש **יהלום**. גוררים יהלום למטה כדי להנמיך את הפיק. Shift+קליק בוחר כמה יהלומים. ליד הקו היהלום נצמד אליו |
| Sibilance | 5 | כל "S" שהפלאגין מזהה מופיע **בלבן** על הגל, ועליו יהלום. גוררים אותו למטה כדי להנמיך את ה‑S. בפאנל: **Sensitivity** (כמה בקלות מסמנים S), **Reduction** (כל ה‑S ביחד), ו‑**Mode**: **Volume** מוריד את כל הצליל של ה‑S, **Filter (highs)** מוריד רק את הגבוהים מעל התדר שבוחרים (כמו דה‑אסר) |

Tab עובר בסבב בין הכלים. **Show S in all tools** בשורת הסטטוס מציג את ה‑S הלבנים גם בכלים האחרים. **לחיצה על מקום ריק בגריד** מזיזה את הסמן, ורווח מנגן ממנו.

**הפאנל בצד** (מקש L או כפתור Loudness מציג או מסתיר אותו):
- **Threshold**: גובה הקו המקווקו. פיקים מעליו מקבלים יהלום.
- **Reduction**: מוריד את **כל** הפיקים שמעל הקו באותה כמות. פיק שגררת ביד שומר על הערך שלו.
- **Selection Analysis**: Peak, True Peak, LUFS, RMS, Crest Factor, ו‑Start, End ו‑Duration של מה שמסומן.

**עריכות נעולות:** כל עריכה של Blob או Peak נשארת בדיוק במקום שלה, גם כשעושים זום.

## DAW: רווח בפלאגין מנגן גם באבלטון (הגדרה חד‑פעמית)
1. מדליקים את כפתור **DAW** בפלאגין. הוא מתקין לבד סקריפט שליטה קטן בתיקיית User Library של אבלטון.
2. מפעילים מחדש את אבלטון.
3. Settings ← Link, Tempo & MIDI ← **Control Surface**: בוחרים **GainEditor**. ב‑Input בוחרים **Gain Editor**, ו‑Output נשאר None.
4. מעכשיו: לוחצים על מקום בגל ← רווח ← אבלטון קופץ לנקודה הזו ומנגן את כל הערוצים.

## קיצורים

| מה | מקש |
|---|---|
| דיוק עדין, פי 10 | מחזיקים **⌥ Option** בזמן גרירה |
| הגברה או הנמכה של מה שמסומן | ↑ ↓ (0.5 dB), ועם Option ‏(0.1 dB) |
| Reset לאזור המסומן | ⌘R, או כפתור Reset, או קליק ימני |
| Reset לכל העריכות | ⇧⌘R (עם אישור) |
| עוצמת האזור המסומן | מחזיקים **L**. עם ⇧L החלון נשאר פתוח |
| Undo / Redo | ⌘Z / ⇧⌘Z |
| זום | + / −, ‏⌘+גלגלת, צביטה בטראקפד, ו‑Z לזום על הסימון |
| זום אנכי (גובה הגל) | Ctrl+גלגלת |
| השמעה בתוך הפלאגין | כפתור Play (מנגן את הסימון) |

**טיפ:** אם מקש לא מגיב, לוחצים פעם אחת בתוך חלון הפלאגין. את מקש הרווח אבלטון בדרך כלל לוקח לעצמו.

## מגבלות בגרסה הזאת
- העבודה ב‑Arrangement View. ב‑Session View אין מיקום קבוע בשיר.
- אם מזיזים את הקליפ באבלטון אחרי ההקלטה, העריכות לא זזות איתו. במקרה כזה מקליטים מחדש.
- הזזה של סליידר הרזולוציה על כל ההקלטה מחליפה רזולוציה שהוגדרה קודם לאזור מסוים, אבל ה‑gain שנתת לבלובים נשמר.
